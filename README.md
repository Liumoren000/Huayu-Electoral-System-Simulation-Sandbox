# 华域 - 选举制度推演沙盒

社会选择与选举制度推演可视化平台。基于中国 350 个地级市（含台湾省 9 城）数据，支持对比不同选举制度下的政治版图、选民行为、政党生态与组阁走向。全模型按现实选举口径校准（适龄选民基数、中国式高动员投票率、多党制得票分化），覆盖主流政治学概念（Duverger 定律、Sartori 类型学、Gallagher 比例性、中间选民定理、政党生态位、超额席位等），并以**整数票数、投票率结构关联、空间自相关、选举取证审计**等机制强化数据真实性，适合学术推演与教学演示。

## 选举制度（下议院，9 种）

| 制度 | 机制 | 真实效应 |
|------|------|----------|
| **小选区制 (FPTP)** | 每选区一席、胜者全得 | 战略弃保挤压小党，胜者红利最大（~+16%），Duverger 收敛 |
| **比例代表制 (PR)** | 全国名单按比例分配 | 席位与选票一致，胜者红利≈0，Gallagher≈0.2% |
| **两轮投票制 (RUNOFF)** | 无人过半进入前两名决选 | 首轮弃保弱化，决选整合，可产生一党独大 |
| **混合成员比例代表制 (MMP)** | 选区席 + 名单席补偿到比例 | **超额席位（overhang）**：选区强势党保留超得席，总席可膨胀 |
| **并立制 (PARALLEL)** | 选区席 + 名单席互不关联 | 名单票与选区票的**分裂选票**现象 |
| **即时复选制 (IRV)** | 排名票逐轮淘汰转移 | 消除"得票多反被边缘化"的废票 |
| **单一可转移投票 (STV)** | 省级多议席、Droop 配额 + 盈余转移 | 整省单选区保留比例性（Gallagher≈1.3），可调 magnitude 拆分选区；投票按城市人口加权 |
| **同意投票 (APPROVAL)** | 对可接受者全部投同意票 | 倾向选出温和、跨阵营可接受者 |
| **波达计分制 (BORDA)** | 按排名给分加权 | 兼顾偏好强度但易受乱序策略操纵 |

- **上议院**：均等代表 / 比例代表 / 混合制，可配置席位数
- **席位分配**：D'Hondt 汉狄法 / Sainte-Laguë 圣拉格法 / 最大余数法 (Hare)
- **得票门槛**：可配置进入议会的最低得票率
- **总席位数**：50-2000（默认 450），每市保底席位

## 真实感增强（选民行为建模）

### 策略性投票 / 弃保（Duverger 效应）
赢者全得的小选区制（FPTP / 混合制选区席）下，选民事前感知哪些政党"有望获胜"，弱势候选人支持者按比例把票转投给可赢政党中与己偏好最接近者；比例代表名单席仍反映真实偏好。**默认启用 0.4**（多数制默认产生制度分化，比例制不受影响）。两轮制首轮弃保压力较弱（阻尼 0.5）。弃保按落后度梯度化（胶着区不整体崩塌），默认限同阵营（camp）转投、跨阵营折半，模拟台湾式"泛蓝/泛绿"阵营内转移。

### 政党体系集中化
全国领先党（第一党 +b、第二党 +b/2）获声望加成，模拟主导党/两强对峙格局（0-0.5 可调）。与弃保叠加可呈现一党主导或两强格局。

### 其他真实感机制
- **适龄选民基数**：以城市年龄结构近似 18+ 占比（全国均值 ≈0.81），实际票数 = 人口 × 适龄占比 × 投票率
- **现实投票率**：0.35-0.85，基准均值约 73%，契合中国式高动员 60-75% 区间
- **城市内选民分层**：按人口结构生成老年保守派、年轻进步派、高学历国际派、产业工人派、农村农业派等亚群中心，混合采样形成异质选民分布
- **历史倾向校准**：以城市基准政党为锚点回拉得票率，模拟既有选举版图的历史惯性
- **政党忠诚（铁票党）**：按政党真实支持强度分配固定忠诚票仓，其余随议题/噪声浮动
- **竞争-投票率联动**：竞争越胶着投票率越高，模拟"弃票/动员"行为，统一作用于全部制度（FPTP/PR/混合制/STV）
- **选区不均衡（malapportionment）**：小城市/农业城市超代表，模拟人口与议席分配错配
- **群体差异化投票率**：老年/高学历/高收入/城市选民投票率更高，按人口结构加权
- **得票率浓缩指数（affinity_power）**：幂次变换放大政党差距，默认 6.0，首党约 24.3%
- **多维加权亲和度**：7 维显式权重（经济 25% / 社会 15% / 区域 15% / 民族 15% / 福利 10% / 环保 10% / 城乡 10%）

### 数据投票真实性（选举公报形态）
- **整数票数**：默认开启，各城市票数以最大余数法取整（真实选举公报的整数形态），全国总票 = 各市整数票之和，得票率与席位不受取整影响
- **投票率结构关联**：城市投票率叠加对数 GDP、教育水平、老龄化结构的系统性影响（发达城市投票率更高），与竞争度联动叠加
- **空间自相关**：同省城市共享省级政治冲击（省级确定性噪声混入城市得票），模拟相邻地区得票更相似的真实地理规律

## 核心指标体系

- **Gallagher / Loosemore-Hanby / Rose 指数**：比例性度量
- **有效政党数**：得票 / 席位两个口径
- **Malapportionment**：议席-人口偏差
- **政党国家化指数**：政党全国分布均匀度
- **胜者红利**：首党席位%-得票%（FPTP≈+16%、MMP≈+4%、PR≈0.2%）
- **极化度**：席位加权意识形态标准差（0-1）
- **不比例性三源分解**：总偏差拆成「选票地理分布 / 省际名额失衡 / 制度机械效应」三来源
- **联盟权力指数**：Banzhaf 与 Shapley-Shubik 博弈论权力指数

## 分析工具（「分析工具 ▾」菜单 17 项 + 页首快捷按钮）

### 空间与地理
- **区域政治版图**：按各省赢家归纳选区集团，附地理标签（沿海带 / 边疆西部带 / 跨区域带 / 区域混合）
- **省域席位流向**（Sankey）：政党 → 省份的席位流向，判断"全国铺开型"还是"区域深耕型"
- **翻转临界席**：按胜差升序列出最接近翻盘的选区，地图黄色高亮高危选区

### 政党与选民
- **政党生态位空间**：政治生态学可视化——各党经济×社会立场定位、生态位宽度、选民覆盖度、党际竞争重叠度（余弦相似度）
- **选民结构构成**：按年龄/教育/城乡/收入四维度拆分全国或某省选票，堆叠条形图 + 自动解读各群体偏好与获胜原因
- **选民模型透明面板**：城市偏好 → 7 维政党亲和度 → 得票率全链路分解
- **选举取证审计**：数据真实性体检——首位数分布 Benford 检验、末位数字均匀性、投票率-竞争度秩相关、边际选区密度，输出 0-100 真实性评分与判语
- **综合代表指数**：多维度加权代表质量雷达图
- **政党空间竞争**：各党在政策空间的距离矩阵与竞争压力

### 制度效应
- **浪费票分析**：各党"浪费票"（远超/低于获得席位的边际票）分解与策略含义
- **代表性缺口**：各党席次-选票偏移的量化归因（地区集中 / 制度机械 / 门槛效应）
- **选区规模效应**：扫描选区 magnitude 对席位-选票比例性、有效政党数的影响
- **碎片化分析**（页首按钮）：对比 FPTP / PR / RUNOFF 下的政党碎片化与首党主导性

### 联盟与政府
- **组阁攻防推演**：手动搭建执政联盟后考察攻防临界·高危翻转席，标注多数告破/第一大党易主风险，计算各党夺权窗口
- **组阁谈判模拟**：按意识形态接近度发出组阁邀请，回放接受/拒绝/达成多数的过程
- **立法推演**：300 次随机模拟给出两院通过率与政党立场图

### 时间与对比
- **历史选举校准**：对比本届与上一届的席位变化、城市翻盘、稳定度、席位波动，并含**选区赢家转移矩阵（选票流）**——上届赢家→本届赢家的城市转移主流方向
- **投票率分析**（页首按钮）：扫描城乡投票率差异权重对有效政党数/Gallagher/最大党的敏感性
- **年份趋势**（页首按钮）：沿全部研究年代（1949-2024 共 9 个）逐年指标折线
- **多快照并列对比**：跨制度/剧本/年份的结果并存同屏对比
- **自动解读报告**：规则引擎基于指标/分解/联盟/临界席生成自然语言结论，覆盖 Sartori 政党体系格局分类、中间选民定理、选举效率、分裂选票、超额席位 (overhang)、三源偏差分解等

## 选举剧本推演

- **选举剧本**：预设宏观事件情景（疫情危机、经济衰退、安全危机、环境灾害、能源危机、社会动荡、人口老龄化、技术革命、候选人丑闻、领袖魅力），每个剧本对投票率、选民偏好、社会不确定性施加扰动
- **多剧本推演台**：运行并累积多个剧本，顶部切换条在「基准 ↔ 各剧本」间切换完整推演视图（地图、席位表、组阁、指标）
- **与选举方案联动**：切换方案 A/B 时全部剧本自动基于新方案重算

## 选举时代（历史年代库）

- 预设建国至今 9 个重大变动年代（1949 建国、1966 文革、1978 改革开放、1992 市场经济、2001 入世、2008 金融危机、2013 新常态、2020 新冠疫情、2024 高质量发展）
- 每个时代对城市数据（GDP/人口/城市化/老龄化/教育/产业）与选民偏好施加一套参数偏移
- 一键切换时代基准并自动重跑，跨时代对比政治版图演变

## 可视化

- **政治地图**：省市两级联动，点击省份下钻到市级，市级显示胜差（>10% 绿 / <3% 橙）
- **半圆议会图**：直观展示各党席位分布（含上议院）
- **制度对比**：方案 A/B 并排——地图高亮翻盘城市/省份，对比有效政党数/Gallagher/最大党/过半政党
- **政党亲和度**：解释城市为何投票给某政党
- **城市明细**：省市钻取时展示各党整数得票（如"沿海商业联盟 12,571,768 票 · 94.5%"）、投票率与市内席位
- **组阁推演**：最小获胜联盟算法

## 配置持久化与分享

- 所有配置自动保存至 localStorage，刷新自动还原
- 「分享」按钮生成 `?s=` 链接（base64url 编码），对方打开即可还原同一配置
- CSV / JSON 一键导出当前方案完整结果
