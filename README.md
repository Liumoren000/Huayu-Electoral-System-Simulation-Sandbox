# 华域 - 选举制度推演沙盒

社会选择与选举制度推演可视化平台。基于中国350个地级市数据，支持对比不同选举制度下的政治版图与组阁走向。

## 快速开始

### 后端

```bash
cd backend
pip install -r requirements.txt
python -m app.main
```

后端运行在 http://localhost:8000

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://localhost:5173

## 功能特性

### 选举制度
- **下议院**: 支持 FPTP（小选区制）和 PR（比例代表制）
- **席位分配**: D'Hondt 汉狄法 / Sainte-Laguë 圣拉格法
- **上议院**: 均等代表、比例代表、混合制，可配置席位数
- **得票门槛**: 可配置进入议会的最低得票率

### 席位分配
- 按人口比例、各省均等、D'Hondt、Sainte-Laguë 四种方法
- 可配置总席位数（50-2000）
- 保底席位（每省/每市最低保障）
- 精确匹配配置总数（最大余数法）

### 可视化
- **政治地图**: 省市两级联动，点击省份下钻到市级
- **半圆议会图**: 直观展示各党席位分布
- **政治倾向**: 每个城市的三维坐标（经济/社会/区域）
- **政党亲和度**: 解释城市为何投票给某政党
- **组阁推演**: 最小获胜联盟算法

### 数据
- 350个地级市完整数据（含人口、GDP、产业结构等）
- 台湾省9个城市
- 7个预设政党，支持光谱坐标编辑
- 年切换（2020-2024）

### 交互
- 政党编辑器：修改名称、光谱位置、启用/禁用
- 手动席位分配：点击省份/城市手动分配
- 实时重算：修改参数后立即更新结果

## 技术栈

- **后端**: FastAPI + Pydantic
- **前端**: React 18 + Vite + ECharts 5
- **数据**: 基于国家统计局年鉴数据估算

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/parties` | GET | 获取预设政党 |
| `/api/cities` | GET | 获取城市数据 |
| `/api/geojson` | GET | 获取中国省级 GeoJSON |
| `/api/geojson/{adcode}` | GET | 获取省级以下 GeoJSON |
| `/api/simulate` | POST | 运行选举推演 |
