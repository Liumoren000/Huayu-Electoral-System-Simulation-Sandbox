# 华域 - 选举制度推演沙盒

社会选择与选举制度推演可视化平台。基于中国350个地级市数据，支持对比不同选举制度下的政治版图与组阁走向。

## 快速开始

### 后端

```bash
cd backend
pip install -r requirements.txt
python -m app.main
```

后端运行在 http://localhost:8000

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://localhost:5173

## 功能特性

### 选举制度
- **下议院**: 支持 9 种制度——
  - 小选区制 (FPTP)
  - 比例代表制 (PR，全国名单)
  - 两轮投票制 (RUNOFF)
  - **混合成员比例代表制 (MMP)**：选区席 + 名单席补位到比例，可调名单占比
  - **并立制 (PARALLEL)**：选区席 + 名单席互不关联
  - **即时复选制 (IRV)**：排名票逐轮淘汰转移
  - **单一可转移投票 (STV)**：省级多议席、Droop 配额 + 盈余转移
  - **同意投票 (APPROVAL)**、**波达计分制 (BORDA)**
- **席位分配**: D'Hondt 汉狄法 / Sainte-Laguë 圣拉格法 / 最大余数法 (Hare)
- **上议院**: 均等代表、比例代表、混合制，可配置席位数
- **得票门槛**: 可配置进入议会的最低得票率

### 席位分配
- 按人口比例、各省均等、D'Hondt、Sainte-Laguë 四种方法
- 可配置总席位数（50-2000）
- 保底席位（每市最低保障，`min_seats_per_city`），超出部分按所选基准分配
- 精确匹配配置总数（最大余数法）

### 稳健性分析
- 蒙特卡洛稳健性：以不同随机种子（seed 1000+i）多次模拟，统计各党席位区间（min/max/中位数/均值）、**95% 置信区间**（2.5/97.5 百分位）、获胜次数、过半次数与整体过半率
- 输出平均有效政党数与 Gallagher 指数，并支持席位区间可视化

### 学术分析工具
- **指标体系**：Gallagher、Loosemore-Hanby、Rose 指数、Malapportionment（议席-人口偏差）、政党国家化指数
- **不比例性三源分解**：把总偏差拆成「选票地理分布 / 省际名额失衡 / 制度机械效应（胜者全得等）」三来源，定位制度偏差的根源（FPTP 以机械效应为主，PR 以地理分布为主）
- **联盟权力指数**：Banzhaf 与 Shapley-Shubik 博弈论权力指数，标记"关键少数"政党
- **敏感性分析**：单因素 ±delta 扰动 tornado 图，识别影响结果的关键参数
- **参数显式化**：选民噪声幅度、排名票抽样选民数、投票率偏移、全国选民偏好倾斜（dim_tilt）均可调

### 分析工具（「分析工具 ▾」菜单）
- **席位—选票偏差气泡图**：横轴选票%、纵轴席位%，虚线为完全比例线，气泡=政党（面积=席位），可同图对比方案 A/B 的偏差方向
- **翻转临界席**：按「第一名−第二名」得票差升序列出最接近翻盘的选区与追赶方，市级地图黄色高亮高危选区
- **省域席位流向**（Sankey）：政党 → 省份的席位流向，判断政党是「全国铺开型」还是「区域深耕型」
- **联盟可能性矩阵**：枚举全部过半联盟、标记最小获胜联盟（去任一党即不过半）、统计各党联盟参与度
- **综合代表指数**：由比例性/名额均衡/全国化/竞争度/多元性/参与度六维合成 0-100 指数，雷达图对比方案 A/B
- **自动解读报告**：规则引擎基于指标/分解/联盟/临界席生成自然语言结论
- **多快照并列对比**：随时「存入快照」，把跨制度/剧本/年份的结果并存，指标与政党席位同屏矩阵对比
- **跨年趋势**：2020→2024 逐年指标折线（有效政党数/第一大党占比/Gallagher/Loosemore/Rose/名额失衡/全国化/投票率）

### 选举剧本推演
- **选举剧本**：预设宏观事件情景（疫情危机、经济衰退、安全危机、环境灾害、能源危机、社会动荡、人口老龄化、经济繁荣、**候选人丑闻风暴**、**领袖魅力效应**），每个剧本对投票率、选民政策偏好（dim_tilt）、社会不确定性施加一套扰动
- **候选人丑闻/领袖魅力**：通过 `party_effects` 直接调整特定政党亲和度（丑闻减分、魅力加分），叠加摇摆选民转向模拟事件级选情波动
- **多剧本推演台**：可运行并累积多个剧本，顶部切换条在「基准 ↔ 各剧本」间快速切换完整推演视图（地图、席位表、组阁、指标），并显示每本的 Gallagher/有效政党数/过半/最大党/总投票 对比
- **与选举方案联动**：切换方案 A/B 时，推演台内所有剧本自动基于新方案重算，便于跨制度比较同一事件的影响

### 真实感增强（选民行为建模）
- **城市内选民分层**：按城市人口结构（老龄化/教育/城镇化/产业）生成老年保守派、年轻进步派、高学历国际派、产业工人派、农村农业派等多个亚群中心，混合采样形成真实异质选民分布
- **历史倾向校准**：以城市基准政党（与城市7维政策位置最近的政党）为锚点回拉得票率，模拟既有选举版图的历史惯性
- **政党忠诚（铁票党）**：设定比例的铁票选民始终投给其基准政党，模拟政党认同的稳定性
- **摇摆选民**：设定比例选民用 3 倍噪声模拟高频波动，作为易变选票的来源
- **竞争-投票率联动（弃票机制）**：竞争越胶着投票率越高、越悬殊越低，模拟选民"弃票/动员"行为
- **选区不均衡（malapportionment）**：小城市/农业城市按比例获得超代表权重，模拟人口变动滞后于议席分配的现实偏差

### 立法推演
- 多维度法案立场配置，结合各政党光谱位置计算支持概率
- 300 次随机模拟，给出下议院/上议院/两院共同通过率与政党立场图

### 城市级下钻
- 点击省份下钻到市级，展示各城市获胜政党、**胜差**（>10% 绿色 / <3% 橙色）、投票率与政治倾向
- 地图 tooltip 同步显示城市胜差

### 竞选民调与舆论推演
- **竞选期民调**：模拟 8-20 周竞选期各党支持率演化曲线（向确定性基准收敛 + 随机波动），叠加首场辩论、经济数据、地方选举、候选人丑闻等**舆论事件冲击**
- **选前预测**：基于最终一周民调输出席位投影，并给出各党「最大党概率」与「过半概率」（当前制度下 200 次蒙特卡洛）

### 选区级摇摆与风向标
- 按各市胜差分位数将选区分为 **胶着（tossup）/ 偏倾（lean）/ 稳固（safe）**
- 识别**风向标选区（bellwether）**：与全国最大党一致、胜差处于中等竞争带的城市，历史上常预示全国走向

### 组阁谈判模拟
- 以第一大党为组阁者，按意识形态接近度依次发出组阁邀请，被邀党依「兼容度 × 席位回报」决定接受或拒绝
- 逐步回放谈判过程（接受/拒绝/达成多数），组阁成功后按最大余数法分配 **20 个部委** 内阁席位

### 选举日实时开票直播
- 模拟选举日各选区按投票站进度**逐步开票**，席位曲线实时累计
- 显示当前领先党、过半门槛与「过半是否仍可达」，进度条 + 动画播放/暂停/重播

### 历史选举校准
- 对比本届与**上一届**（默认 year-4，人口/GDP 缩放 + 不同随机种子）的席位变化、城市翻盘与第一大党是否易主
- 输出稳定度（连任城市占比）、席位波动率，并按城市筛选翻盘/连任明细

### 配置持久化与分享
- 所有配置（政党、席位、制度、年度）自动保存至 localStorage，刷新自动还原
- 「分享」按钮生成 `?s=` 链接（base64url 编码，无 padding），对方打开即可还原同一配置

### 可视化
- **政治地图**: 省市两级联动，点击省份下钻到市级
- **制度对比**: 一键对比方案A/B——地图高亮翻盘城市/省份（胜者改变），并排展示有效政党数、Gallagher 指数、最大党与过半政党，以及 A/B 席位差异表
- **半圆议会图**: 直观展示各党席位分布
- **政治倾向**: 每个城市的三维坐标（经济/社会/区域）
- **政党亲和度**: 解释城市为何投票给某政党
- **组阁推演**: 最小获胜联盟算法

### 数据
- 350个地级市完整数据（含人口、GDP、产业结构等）
- 台湾省9个城市
- 7个预设政党，支持光谱坐标编辑
- 年切换（2020-2024）

### 交互
- 政党编辑器：修改名称、光谱位置、启用/禁用
- 手动席位分配：点击省份/城市手动分配
- 实时重算：修改参数后立即更新结果

## 技术栈

- **后端**: FastAPI + Pydantic
- **前端**: React 18 + Vite + ECharts 5
- **数据**: 基于国家统计局年鉴数据估算

## API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/parties` | GET | 获取预设政党 |
| `/api/cities` | GET | 获取城市数据 |
| `/api/geojson` | GET | 获取中国省级 GeoJSON |
| `/api/geojson/{adcode}` | GET | 获取省级以下 GeoJSON |
| `/api/simulate` | POST | 运行选举推演（支持 `voter_stratification` / `party_loyalty` / `swing_voter_pct` / `abstention_sensitivity` / `malapportionment` / `party_effects` / `calibration` 真实感参数） |
| `/api/simulate/robustness` | POST | 蒙特卡洛稳健性分析（含省级/城市级不确定性） |
| `/api/simulate/sensitivity` | POST | 关键参数敏感性分析 |
| `/api/simulate/poll` | POST | 竞选期民调与舆论推演（支持率曲线 + 席位投影 + 胜率预测） |
| `/api/simulate/swing` | POST | 选区级摇摆/风向标分析（tossup/lean/safe + bellwether） |
| `/api/simulate/rolling-count` | POST | 选举日实时开票（逐步累计席位与领先党） |
| `/api/simulate/calibrate` | POST | 历史选举校准（上届对比、城市翻盘、稳定度） |
| `/api/voter-model/explain` | POST | 选民行为模型透明分解（城市偏好→政党亲和度） |
